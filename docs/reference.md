# API reference

ARCExpect is implemented once in F# and exposes the same domain model across
.NET, JavaScript, and Python. The generated F# reference is therefore the
authoritative structural reference; the guides show the native imports and
async conventions for every runtime.

**[Open the ARCExpect API reference](/arc-validate/fsdocs/reference/index.html)**

!!! note
    The reference is generated into `site/fsdocs/` by `BuildDocs`. A standalone
    `mkdocs serve` preview renders the guide but does not regenerate this subsite.
